# SistemiBazaProjekat
Projekat iz Sistema Baza Podataka
Tema: Repozitorijum Naučno istraživačkog centra

Projekat radili:
- Andrija Lazić
- Marko Nikolić

### O projektu
Repozitorijuma Naučno Istraživačkog centra je projekat sa predmeta Sistema Baza Podataka na Elektronskom Fakultetu u Niš. Predstavlja rad baze koja evidentira Istraživače, njihove uloge i Istraživačke radove pomenutih istraživača.

Projekat se sastoji od Oracle Baze kreirane preko SQL Skripte (Poslednja verzija: SkriptaZaBazuIspravljena.sql) i aplikacija u Windows ( Folder Digitalni Repozitorijum) / Web Aplikaciji ( Folder WebApp2 ).
Tehnologija za pristup bazi i mapiranja preko aplikacija je rađena pomoću Fluent NHibernate-a.
